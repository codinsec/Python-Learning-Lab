# Section 3: Advanced Python

## Overview
This section covers advanced Python features that make the language powerful and expressive. You'll learn about generators, decorators, context managers, error handling, async programming, and magic methods.

## Learning Path
Follow these topics in order:

1. **11-Generators-Iterators** - Creating memory-efficient iterators with `yield`
2. **12-Decorators-Closures** - Modifying functions with decorators and understanding closures
3. **13-Context-Managers** - Managing resources with the `with` statement
4. **14-Error-Handling** - Handling exceptions and creating custom exceptions
5. **15-Async-Programming** - Writing concurrent code with `asyncio` and `async`/`await`
6. **16-Magic-Methods** - Customizing object behavior with dunder methods

## Expected Outcome
After completing this section, you will be able to:
- Write memory-efficient code using generators
- Create and use decorators effectively
- Manage resources with context managers
- Handle errors gracefully with custom exceptions
- Write concurrent code using async/await
- Customize object behavior with magic methods

## How to Use This Section
1. Start with `11-generators-iterators` and work through each topic sequentially
2. Read the README.md in each topic folder for learning objectives
3. Run the examples in `main.py` to see concepts in action
4. Experiment by modifying the code examples
