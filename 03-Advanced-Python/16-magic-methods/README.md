# Magic Methods (Dunder Methods)

## Overview
This topic covers Python's magic methods (dunder methods) - special methods that allow you to define how objects behave with built-in operations. Learn how to customize object behavior using methods like `__str__`, `__repr__`, `__len__`, `__call__`, and many more.

## Learning Objectives
- Understand magic methods and their purpose
- Implement string representation methods (`__str__`, `__repr__`)
- Override comparison operators (`__eq__`, `__lt__`, etc.)
- Implement arithmetic operators (`__add__`, `__sub__`, etc.)
- Use `__call__` to make objects callable
- Implement container methods (`__len__`, `__getitem__`, etc.)
- Understand `__init__` and `__new__`
- Work with context manager methods

## Topics Covered
- String representation (`__str__`, `__repr__`)
- Comparison operators (`__eq__`, `__lt__`, `__le__`, etc.)
- Arithmetic operators (`__add__`, `__sub__`, `__mul__`, etc.)
- Type conversion (`__int__`, `__float__`, `__bool__`)
- Container methods (`__len__`, `__getitem__`, `__setitem__`, `__contains__`)
- Callable objects (`__call__`)
- Attribute access (`__getattr__`, `__setattr__`, `__delattr__`)
- Context manager methods (`__enter__`, `__exit__`)
