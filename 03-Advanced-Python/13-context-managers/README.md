# Context Managers

## Overview
This topic covers context managers in Python, which allow you to manage resources properly using the `with` statement. Learn how to create custom context managers and use them for resource management.

## Learning Objectives
- Understand the `with` statement
- Use built-in context managers (files, etc.)
- Create custom context managers using classes
- Use the `@contextmanager` decorator
- Understand `__enter__` and `__exit__` methods
- Handle exceptions in context managers
- Work with multiple context managers

## Topics Covered
- The `with` statement
- Built-in context managers
- Custom context managers (class-based)
- Context manager protocol (`__enter__`, `__exit__`)
- The `contextlib` module
- `@contextmanager` decorator
- Exception handling in context managers

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- File handling with context managers
- Custom context manager classes
- Using `@contextmanager` decorator
- Exception handling
- Multiple context managers
