# Decorators and Closures

## Overview
This topic covers decorators and closures in Python. Learn how to modify or extend functions using decorators, understand closures and their use cases, and create both simple and advanced decorators.

## Learning Objectives
- Understand closures and how they work
- Create simple decorators
- Use decorator syntax (`@decorator`)
- Create decorators with arguments
- Understand decorator chaining
- Work with class-based decorators
- Use `functools.wraps` to preserve function metadata

## Topics Covered
- Closures and nested functions
- Basic decorators
- Decorator syntax
- Decorators with arguments
- Decorator chaining
- Class-based decorators
- `functools.wraps` for metadata preservation
- Common decorator patterns

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Closure creation and usage
- Function decorators
- Decorators with parameters
- Class decorators
- Real-world decorator patterns
