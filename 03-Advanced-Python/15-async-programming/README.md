# Async Programming

## Overview
This topic covers asynchronous programming in Python using `asyncio`. Learn how to write concurrent code using `async`/`await`, work with coroutines, tasks, and understand event loops.

## Learning Objectives
- Understand asynchronous programming concepts
- Use `async` and `await` keywords
- Create and run coroutines
- Work with `asyncio` event loop
- Create and manage tasks
- Use `asyncio.gather()` for concurrent execution
- Handle async exceptions
- Work with async context managers

## Topics Covered
- Async/await syntax
- Coroutines
- Event loops
- Tasks and futures
- Concurrent execution with `asyncio.gather()`
- Async context managers
- Async generators
- Error handling in async code

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic async functions
- Running coroutines
- Concurrent task execution
- Async context managers
- Error handling in async code
