# Generators and Iterators

## Overview
This topic covers generators and iterators in Python. Learn how to create memory-efficient iterators using the `yield` keyword, understand the iterator protocol, and work with generator expressions.

## Learning Objectives
- Understand the difference between iterators and iterables
- Create generators using the `yield` keyword
- Use generator expressions for concise code
- Understand the iterator protocol (`__iter__`, `__next__`)
- Create custom iterator classes
- Work with infinite generators
- Understand generator state and execution flow

## Topics Covered
- Iterables vs iterators
- The `yield` keyword
- Generator functions
- Generator expressions
- The iterator protocol
- Custom iterator classes
- Infinite generators
- Generator pipelines

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic generator functions
- Generator expressions
- Custom iterator classes
- Infinite generators
- Generator pipelines and chaining
