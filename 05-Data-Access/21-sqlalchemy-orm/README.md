# SQLAlchemy ORM

## Overview
This topic covers SQLAlchemy ORM (Object-Relational Mapping), Python's powerful database toolkit. Learn how to define models, create relationships, and interact with databases using Python objects instead of raw SQL.

## Learning Objectives
- Understand ORM concepts and benefits
- Define SQLAlchemy models
- Create database sessions
- Perform CRUD operations with ORM
- Define relationships (one-to-many, many-to-one)
- Use query API instead of raw SQL
- Understand sessions and transactions

## Topics Covered
- SQLAlchemy setup and installation
- Model definition with declarative base
- Column types and constraints
- Creating and dropping tables
- Session management
- CRUD operations (Create, Read, Update, Delete)
- Relationships and foreign keys
- Query API

## How to Run
```bash
python main.py
```

**Note:** Requires SQLAlchemy: `pip install sqlalchemy`

## Examples
The `main.py` file contains practical examples demonstrating:
- Model definition
- Database operations
- Relationships
- Query building
