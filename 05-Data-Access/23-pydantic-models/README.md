# Pydantic Models

## Overview
This topic covers Pydantic, a data validation library for Python. Learn how to create data models with automatic validation, type checking, and serialization. Pydantic is essential for API development and data validation.

## Learning Objectives
- Understand Pydantic and its benefits
- Create Pydantic models
- Use field validators
- Handle validation errors
- Serialize and deserialize data
- Work with nested models
- Use Pydantic with FastAPI

## Topics Covered
- Pydantic model definition
- Field types and validation
- Custom validators
- Model serialization (to dict, JSON)
- Model deserialization (from dict, JSON)
- Nested models
- Model configuration

## How to Run
```bash
python main.py
```

**Note:** Requires Pydantic: `pip install pydantic`

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic model creation
- Field validation
- Custom validators
- Serialization/deserialization
- Nested models
