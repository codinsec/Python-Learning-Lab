# SQLite Basics

## Overview
This topic covers working with SQLite databases in Python. Learn how to create databases, execute SQL queries, handle transactions, and work with the `sqlite3` module.

## Learning Objectives
- Understand SQLite and its use cases
- Create and connect to SQLite databases
- Execute SQL queries (CREATE, INSERT, SELECT, UPDATE, DELETE)
- Work with cursors and fetch results
- Handle transactions
- Use parameterized queries for safety
- Understand database schema design basics

## Topics Covered
- SQLite database creation
- Connection management
- SQL query execution
- Cursor operations
- Parameterized queries
- Transactions and commits
- Error handling in database operations

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Creating databases and tables
- Inserting, querying, updating, and deleting data
- Using parameterized queries
- Working with transactions
- Error handling
