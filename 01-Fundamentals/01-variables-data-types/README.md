# Variables and Data Types

## Overview
This topic covers Python's dynamic typing system and fundamental data types. Python is dynamically typed, meaning you don't need to declare variable types explicitly - Python infers types at runtime.

## Learning Objectives
- Understand Python's dynamic typing system
- Learn about basic data types: int, float, str, bool, None
- Practice variable assignment and naming conventions
- Explore type checking and conversion

## Topics Covered
- Variable assignment and naming (snake_case)
- Integer and floating-point numbers
- Strings and string operations
- Boolean values and truthiness
- None type
- Type conversion (casting)

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Creating variables with different data types
- Type checking and conversion
- Variable naming conventions following PEP 8
