# Functions and Lambda

## Overview
This topic covers function definition, parameters, arguments, and lambda functions in Python. Learn how to create reusable code blocks and work with *args and **kwargs for flexible function signatures.

## Learning Objectives
- Define and call functions
- Understand function parameters and arguments
- Master default parameters and keyword arguments
- Learn *args and **kwargs for variable arguments
- Create lambda functions (anonymous functions)
- Understand function scope and closures

## Topics Covered
- Function definition and calling
- Positional and keyword arguments
- Default parameter values
- *args (variable positional arguments)
- **kwargs (variable keyword arguments)
- Lambda functions
- Function scope and local/global variables

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic function definitions
- Different argument types
- Lambda functions for simple operations
- Advanced argument handling
