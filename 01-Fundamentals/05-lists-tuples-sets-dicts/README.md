# Lists, Tuples, Sets, and Dictionaries

## Overview
This topic covers Python's core data structures: lists, tuples, sets, and dictionaries. These are the heart of Python programming and understanding them is crucial for effective Python development.

## Learning Objectives
- Master list operations (creation, indexing, slicing, methods)
- Understand tuples (immutable sequences)
- Work with sets (unique collections)
- Master dictionaries (key-value mappings)
- Learn list comprehensions and dictionary comprehensions
- Understand when to use each data structure

## Topics Covered
- Lists: creation, indexing, slicing, methods (append, extend, insert, remove, etc.)
- Tuples: immutable sequences, unpacking
- Sets: unique collections, set operations (union, intersection, difference)
- Dictionaries: key-value pairs, methods, iteration
- Comprehensions: list, set, and dictionary comprehensions
- Nested data structures

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- All major operations for each data structure
- Common patterns and use cases
- Comprehensions for concise code
- Nested structures
