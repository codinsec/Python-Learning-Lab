# Section 1: Fundamentals

## Overview
This section covers Python's fundamental concepts and syntax. You'll learn about Python's dynamic typing system, control flow, functions, and core data structures.

## Learning Path
Follow these topics in order:

1. **01-Variables-DataTypes** - Understanding Python's dynamic typing and basic data types
2. **02-Conditionals-Loops** - Control flow with conditionals and loops, including match-case
3. **03-Functions-Lambda** - Function definition, parameters, *args, **kwargs, and lambda functions
4. **04-Strings-Numbers-Dates** - String manipulation, numeric operations, and date/time handling
5. **05-Lists-Tuples-Sets-Dicts** - Python's core data structures

## Expected Outcome
After completing this section, you will be able to:
- Write basic Python scripts with proper syntax
- Use Python's dynamic typing effectively
- Implement control flow logic
- Create reusable functions
- Work with strings, numbers, and dates
- Manipulate lists, tuples, sets, and dictionaries

## How to Use This Section
1. Start with `01-variables-data-types` and work through each topic sequentially
2. Read the README.md in each topic folder for learning objectives
3. Run the examples in `main.py` to see concepts in action
4. Experiment by modifying the code examples
