# Conditionals and Loops

## Overview
This topic covers control flow in Python: conditional statements (if/elif/else), loops (for/while), and the modern match-case statement introduced in Python 3.10.

## Learning Objectives
- Master if/elif/else conditional statements
- Understand for loops and while loops
- Learn the match-case statement (Python 3.10+)
- Practice loop control with break, continue, and else clauses
- Explore list comprehensions and generator expressions

## Topics Covered
- Conditional statements (if, elif, else)
- Comparison and logical operators
- For loops (iterating over sequences)
- While loops (conditional iteration)
- Match-case statements (pattern matching)
- Loop control statements (break, continue, else)
- Nested loops

## How to Run
```bash
python main.py
```
