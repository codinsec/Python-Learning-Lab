# Strings, Numbers, and Dates

## Overview
This topic covers string manipulation, numeric operations, and date/time handling in Python. Learn how to work with text data, perform mathematical operations, and handle dates and times effectively.

## Learning Objectives
- Master string operations and methods
- Understand string formatting (f-strings, format method)
- Work with numeric types and operations
- Handle dates and times using datetime module
- Format and parse dates
- Perform date arithmetic

## Topics Covered
- String creation and manipulation
- String methods (upper, lower, split, join, etc.)
- String formatting (f-strings, .format())
- Numeric operations and math module
- Date and time with datetime module
- Date formatting and parsing
- Timezone handling

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- String operations and formatting
- Numeric calculations
- Date and time operations
- Common string and date patterns
