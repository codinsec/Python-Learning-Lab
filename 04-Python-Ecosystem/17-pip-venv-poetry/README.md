# Pip, Venv, and Poetry

## Overview
This topic covers Python package management and virtual environment tools. Learn how to manage dependencies, create isolated environments, and use modern tools like Poetry for project management.

## Learning Objectives
- Understand the importance of virtual environments
- Create and manage virtual environments with `venv`
- Install and manage packages with `pip`
- Use `requirements.txt` for dependency management
- Understand Poetry for modern dependency management
- Work with `pyproject.toml` files
- Manage project dependencies effectively

## Topics Covered
- Virtual environments (`venv`)
- Package installation with `pip`
- `requirements.txt` file
- Poetry installation and setup
- `pyproject.toml` configuration
- Poetry commands (add, remove, install, update)
- Dependency resolution

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Virtual environment creation and activation
- Package management workflows
- Requirements file usage
- Poetry project setup (conceptual examples)

**Note:** Some examples are conceptual as they require actual package installations.
