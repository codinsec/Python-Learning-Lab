# Logging and Configuration

## Overview
This topic covers Python's logging module and configuration management. Learn how to implement proper logging, use different log levels, configure loggers, and manage application settings with environment variables and config files.

## Learning Objectives
- Use Python's `logging` module effectively
- Understand log levels (DEBUG, INFO, WARNING, ERROR, CRITICAL)
- Configure loggers and handlers
- Create custom log formats
- Use environment variables with `python-dotenv`
- Manage application configuration
- Implement file and console logging

## Topics Covered
- Logging module basics
- Log levels and when to use them
- Logger configuration
- Handlers (FileHandler, StreamHandler, etc.)
- Formatters and log formatting
- Environment variables (.env files)
- Configuration management patterns

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic logging setup
- Different log levels
- File and console logging
- Custom formatters
- Environment variable management
- Configuration patterns
