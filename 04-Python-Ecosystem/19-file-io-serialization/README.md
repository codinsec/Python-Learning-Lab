# File I/O and Serialization

## Overview
This topic covers file input/output operations and data serialization in Python. Learn how to read and write files, work with different file formats (JSON, Pickle, CSV), and handle file operations safely.

## Learning Objectives
- Read and write text files
- Work with binary files
- Use context managers for file operations
- Serialize and deserialize data with JSON
- Use Pickle for Python object serialization
- Read and write CSV files
- Handle file errors and edge cases

## Topics Covered
- File reading and writing
- Text vs binary file modes
- Context managers for files
- JSON serialization (`json` module)
- Pickle serialization (`pickle` module)
- CSV reading and writing (`csv` module)
- File path operations (`os.path`, `pathlib`)

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic file operations
- JSON serialization
- Pickle usage
- CSV file handling
- Error handling in file operations
