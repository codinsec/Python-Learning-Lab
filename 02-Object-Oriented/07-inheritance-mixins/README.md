# Inheritance and Mixins

## Overview
This topic covers inheritance in Python, allowing classes to inherit attributes and methods from parent classes. Learn about single and multiple inheritance, method overriding, the `super()` function, and the powerful mixin pattern.

## Learning Objectives
- Understand inheritance and its benefits
- Implement single and multiple inheritance
- Override parent class methods
- Use the `super()` function to call parent methods
- Understand Method Resolution Order (MRO)
- Implement mixins for code reuse
- Work with `isinstance()` and `issubclass()`

## Topics Covered
- Single inheritance
- Multiple inheritance
- Method overriding
- The `super()` function
- Method Resolution Order (MRO)
- Mixins pattern
- Type checking with `isinstance()` and `issubclass()`

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic inheritance patterns
- Method overriding
- Using super() to extend parent behavior
- Multiple inheritance scenarios
- Mixin classes for reusable functionality
