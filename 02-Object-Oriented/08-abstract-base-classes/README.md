# Abstract Base Classes (ABC)

## Overview
This topic covers Abstract Base Classes (ABC) in Python using the `abc` module. Learn how to define abstract methods that must be implemented by subclasses, creating contracts for class hierarchies.

## Learning Objectives
- Understand the concept of abstract classes
- Use the `abc` module to create abstract base classes
- Define abstract methods using `@abstractmethod`
- Implement abstract classes in concrete subclasses
- Understand when to use ABCs vs regular inheritance
- Work with abstract properties

## Topics Covered
- The `abc` module
- Abstract base classes
- Abstract methods with `@abstractmethod`
- Abstract properties
- Concrete implementations
- Interface-like behavior in Python

```bash
python main.py
```

The `main.py` file contains practical examples demonstrating:

- Using ABCs to enforce contracts
