# Dataclasses and Enums

## Overview
This topic covers modern Python data structures: dataclasses for creating classes with less boilerplate, and enums for defining sets of named constants. These are powerful tools for writing clean, maintainable Python code.

## Learning Objectives
- Understand dataclasses and their benefits
- Create dataclasses with `@dataclass` decorator
- Use default values and field defaults
- Understand dataclass features (frozen, order, etc.)
- Create and use enums
- Work with enum members and values
- Use IntEnum and Flag enums

## Topics Covered
- The `@dataclass` decorator
- Dataclass fields and defaults
- Dataclass methods (`__init__`, `__repr__`, `__eq__`)
- Frozen dataclasses (immutable)
- The `Enum` class
- Enum members and values
- `IntEnum` and `Flag` enums
- Enum iteration and comparison

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic dataclass creation
- Dataclass with defaults and field options
- Frozen dataclasses
- Enum definitions and usage
- Advanced enum patterns
