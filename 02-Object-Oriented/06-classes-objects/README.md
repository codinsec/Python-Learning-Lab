# Classes and Objects

## Overview
This topic covers object-oriented programming fundamentals in Python. Learn how to create classes, instantiate objects, work with instance variables and methods, and understand the `self` parameter.

## Learning Objectives
- Understand the concept of classes and objects
- Create classes with attributes and methods
- Instantiate objects from classes
- Work with instance variables and methods
- Understand the `self` parameter
- Use constructors (`__init__`) and other special methods
- Implement class methods and static methods

## Topics Covered
- Class definition syntax
- Object instantiation
- Instance variables and methods
- The `self` parameter
- Constructor method (`__init__`)
- Class variables vs instance variables
- Class methods and static methods
- Special methods (dunder methods)

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Basic class definition and object creation
- Instance variables and methods
- Class variables
- Class methods and static methods
- Common patterns in OOP
