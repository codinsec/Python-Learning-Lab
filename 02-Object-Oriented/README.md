# Section 2: Object-Oriented Programming

## Overview
This section covers object-oriented programming in Python. You'll learn how to create classes, work with inheritance, use abstract base classes, implement encapsulation with properties, and leverage modern Python features like dataclasses and enums.

## Learning Path
Follow these topics in order:

1. **06-Classes-Objects** - Understanding classes, objects, instance methods, and class methods
2. **07-Inheritance-Mixins** - Single and multiple inheritance, method overriding, and mixins
3. **08-Abstract-Base-Classes** - Creating abstract base classes with the `abc` module
4. **09-Encapsulation-Properties** - Private attributes, properties, and getter/setter methods
5. **10-Dataclasses-Enums** - Modern Python data structures: dataclasses and enums

## Expected Outcome
After completing this section, you will be able to:
- Design and implement classes following OOP principles
- Use inheritance to create class hierarchies
- Define abstract base classes to enforce contracts
- Implement encapsulation with properties
- Use dataclasses and enums for cleaner code
- Apply Pythonic OOP patterns

## How to Use This Section
1. Start with `06-classes-objects` and work through each topic sequentially
2. Read the README.md in each topic folder for learning objectives
3. Run the examples in `main.py` to see concepts in action
4. Experiment by modifying the code examples
