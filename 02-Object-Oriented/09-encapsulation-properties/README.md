# Encapsulation and Properties

## Overview
This topic covers encapsulation in Python, including private attributes, the `@property` decorator, and getter/setter methods. Learn how to control access to class attributes and implement computed properties.

## Learning Objectives
- Understand encapsulation principles
- Use name mangling for private attributes
- Implement properties with `@property` decorator
- Create getter and setter methods
- Use `@property.setter` and `@property.deleter`
- Understand when to use properties vs direct attribute access

## Topics Covered
- Encapsulation concepts
- Private attributes (name mangling with `__`)
- Protected attributes (convention with `_`)
- The `@property` decorator
- Getter, setter, and deleter methods
- Computed properties
- Property validation

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Private and protected attributes
- Property decorators
- Getter and setter methods
- Property validation
- Computed properties
