# SOLID Principles - Pythonic Examples

## Overview
This topic covers SOLID principles applied to Python code. Learn how to write maintainable, extensible, and testable code following Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, and Dependency Inversion principles.

## Learning Objectives
- Understand each SOLID principle
- Apply SOLID principles in Python
- Recognize violations of SOLID principles
- Refactor code to follow SOLID principles
- Write Pythonic code that adheres to SOLID
- Understand trade-offs and when to apply principles

## Topics Covered
- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)
- Pythonic implementations
- Real-world examples

## How to Run
```bash
python main.py
```

## Examples
The `main.py` file contains practical examples demonstrating:
- Each SOLID principle
- Violations and how to fix them
- Pythonic implementations
- Real-world scenarios
