# Unit Testing with Pytest

## Overview
This topic covers unit testing in Python using Pytest. Learn how to write test cases, use fixtures, organize tests, and follow testing best practices. Pytest is a powerful testing framework that makes writing and running tests easy.

## Learning Objectives
- Write unit tests with Pytest
- Use test fixtures for setup and teardown
- Organize tests in classes and modules
- Use assertions effectively
- Handle exceptions in tests
- Use parametrized tests
- Understand test discovery and execution

## Topics Covered
- Pytest installation and setup
- Basic test functions
- Assertions and test failures
- Test fixtures
- Parametrized tests
- Test classes
- Exception testing
- Test organization

## How to Run
```bash
# Install pytest
pip install pytest

# Run all tests
pytest

# Run specific test file
pytest test_main.py

# Run with verbose output
pytest -v

# Run with coverage
pytest --cov
```

## Examples
The `main.py` file contains code to test, and `test_main.py` contains test examples demonstrating:
- Basic test functions
- Fixtures
- Parametrized tests
- Exception testing
