# Python Learning Lab

A comprehensive, structured learning path for mastering Python from fundamentals to advanced topics, including web development, data access, and testing.

## 🎯 Purpose

This repository provides a step-by-step, disciplined approach to learning Python, covering:

- **Python Fundamentals** (Python 3.10+)
- **Modern Web API Development** (FastAPI)
- **Data Processing and Access**
- **Testing, SOLID Principles, and Advanced Python Features**

## 📚 Learning Structure

The repository is organized into 7 main sections, each building upon the previous:

### 🟢 Section 1: Fundamentals
**Path:** `01-Fundamentals/`

Learn Python syntax, dynamic typing, and core data structures.

- Variables and Data Types
- Conditionals and Loops (including match-case)
- Functions and Lambda
- Strings, Numbers, and Dates
- Lists, Tuples, Sets, and Dictionaries

### 🟢 Section 2: Object-Oriented Programming
**Path:** `02-Object-Oriented/`

Master Pythonic object-oriented programming.

- Classes and Objects
- Inheritance and Mixins
- Abstract Base Classes (ABC)
- Encapsulation and Properties
- Dataclasses and Enums

### 🟡 Section 3: Advanced Python
**Path:** `03-Advanced-Python/`

Explore Python's powerful features and asynchronous programming.

- Generators and Iterators
- Decorators and Closures
- Context Managers
- Error Handling
- Async Programming (Asyncio)
- Magic Methods (Dunder Methods)

### 🟡 Section 4: Python Ecosystem
**Path:** `04-Python-Ecosystem/`

Learn package management and environment setup.

- Pip, Venv, and Poetry
- Logging and Configuration
- File I/O and Serialization (JSON, Pickle, CSV)

### 🟠 Section 5: Data Access
**Path:** `05-Data-Access/`

Work with databases and data modeling.

- SQLite Basics
- SQLAlchemy ORM
- Migrations (Alembic)
- Pydantic Models

### 🔵 Section 6: Web Development
**Path:** `06-Web-Development/`

Build modern, fast web services with FastAPI.

- FastAPI Basics and Routing
- Dependency Injection in FastAPI
- Middleware and CORS
- Authentication (JWT, OAuth2)

### 🔴 Section 7: Testing & Architecture
**Path:** `07-Testing-Architecture/`

Develop maintainable, bug-free software.

- Unit Testing (Pytest)
- Mocking and Integration Tests
- SOLID Principles
- Design Patterns

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or higher
- Git

### How to Use This Repository

1. **Clone the repository:**
   ```bash
   git clone https://github.com/codinsec/Python-Learning-Lab.git
   cd Python-Learning-Lab
   ```

2. **Start with Section 1:**
   - Navigate to `01-Fundamentals/`
   - Read the section README.md
   - Work through each topic in order
   - Run examples with `python main.py`

3. **Follow the Learning Path:**
   - Complete each section sequentially
   - Read the README.md in each topic folder
   - Experiment with the code examples
   - Modify examples to deepen understanding

## 📋 Code Standards

This repository follows Python best practices:

- **PEP 8 Compliance**: All code follows PEP 8 standards
- **Naming Conventions**: 
  - Variables and functions: `snake_case`
  - Classes: `PascalCase`
  - Files and folders: `snake_case`
- **Comments**: All comments are in English
- **No Type Hints**: Focus on Python's dynamic typing nature
- **Documentation**: All README files are in English

## 🛠️ Virtual Environment

**Important:** Always use a virtual environment for each section or project.

```bash
# Create virtual environment
python -m venv .venv

# Activate (Windows)
.venv\Scripts\activate

# Activate (Linux/Mac)
source .venv/bin/activate
```

Never install packages globally!
